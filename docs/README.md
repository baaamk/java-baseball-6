## 프로그램

### 게임 시작 문구 출력 기능
- [x] 게임 시작 문구 상수화 

### 컴퓨터 3자리 수 생성 기능
- [ ] 3자리 수 생성하는 함수 구현
  - [ ] `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용
  - [ ] 중복된 숫자가 있으면 안된다

### 플레이어 입력 기능
- [ ] 3자리 수 입력하는 함수 구현
  - [ ] `camp.nextstep.edu.missionutils.Console`의 `readLine()` 활용
- [ ] 잘못된 값을 입력할 경우 `IllegalArgumentException` 발생
  - [ ] 숫자가 아닌 문자를 입력할 경우
  - [ ] 0을 입력하는 경우
  - [ ] 중복된 숫자를 입력하는 경우
  - [ ] 3자리 수를 넘어갈 경우

### 힌트 출력하는 기능
- [ ] computer 와 player 숫자 비교 함수
  - [ ] 같은 자리 같은 수이면 스트라이크
  - [ ] 다른 자리 같은 수이면 볼
- [ ] 스트라이크와 볼의 개수에 따른 출력
  - [ ] 볼과 스트라이크 모두 1 이상이라면 "1볼1스트라이크"와 같이 출력
  - [ ] 볼만 있을 경우 "2볼"와 같이 출력
  - [ ] 스트라이크만 있을 경우 "2스트라이크"와 같이 출력
  - [ ] 볼과 스트라이크 모두 0일 경우 "낫싱" 출력

### 게임 재시작 혹은 종료 선택 기능
- [ ] 3개의 숫자를 모두 맞힐 경우, 사용자에게 재시작 및 종료 여부를 묻는 함수
  - [ ] 사용자에게 재시작 혹은 종료 여부 묻는 구문 출력
  - [ ] 사용자에게 1 혹은 2의 입력을 받는다.
- [ ] 유효성 검사
  - [ ] 입력에 숫자 1, 2가 아닌 다른 문자를 입력할 경우
  - [ ] 입력의 길이가 1이 아닐 경우
