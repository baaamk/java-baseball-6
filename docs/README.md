## 프로그램
- [ ] 컴퓨터
  - [ ] 1에서 9 사이 임의의 수 3개의 수 선택
  - [ ] 결과 출력
    - [ ] 같은 자리 같은 수 -> 스트라이크
    - [ ] 다른 자리 같은 수 -> 볼
    - [ ] 전혀 다른 수 -> 낫싱
- [ ] 플레이어
  - [ ] 3자리 수 입력
    - [ ] 잘못된 값을 입력할 경우 IllegalArgumentException 발생
      - [ ] 숫자가 아닌 값을 입력할 경우 -> 글자, 특수문자
      - [ ] 0을 입력할 경우
      - [ ] 3자리 초과할 경우
      - [ ] 중복된 숫자가 있을 경우
- [ ] 게임
  - [x] 시작 문구 출력
  - [ ] 3스트라이크 -> 게임 종료
  - [ ] 종료 후 다시 시작하거나 완전히 종료
