# 숫자야구 요구사항 정리

## 요구사항
### 기능
- [x] 같은 수가 자리에 있으면 스트라이크
- [x] 다른 자리에 있으면 볼
- [x] 같은 수가 전혀 없으면 낫싱 이라는 힌트
- [x] 컴퓨터는 1에서 9까지 서로 다른 임의의 수 3개를 선택
- [x] 반복해 컴퓨터가 선택한 3개의 숫자를 모두 맞히면 게임 종료
- [x] 게임 종료 후 다시시작 또는 완전 종류 가능
- [x] 잘못된 입력을 하면 애플리케이션 종료
- [x] 모든 것에 대한 검증
- [x] 숫자는 중복을 허용하지 않음

### 입력
- [x] 서로 다른 3자리의 수
- [x] 게임이 끝난 경우 재시작 종료를 구별하는 1과 2중 하나의 수


### 출력
- [x] 입력한 수에 대한 결과 볼, 스트라이크 개수 표시
- [x] 하나도 없으면 낫싱
- [x] 3개 다 맞추면 맞췄다는 내용 출력
- [x] 게임 시작 문구 출력
- [x] 재시작 문구 출력
---
## 예외
- [x] 숫자 입력에 3자리 이상의 숫자 입력
- [x] 문자 입력
- [x] 공백 입력
- [x] 재시작에 1,2 이외의 숫자 입력
